# Changelog

## 1.1.0 (2026-10-11)

- Seven broad skills: `qgis`, `gis-data`, `spatial-analysis`, `remote-sensing`, `cartography`,
  `object-detection`, `spatial-sql`. Each is organized as ordered workflows with a check at every
  step, based on GIS agent benchmarks, user requests and tests on QGIS 3.44, GDAL and DuckDB.
- The eight 1.0 skills are merged into them. Their folders remain as pointers so existing links and
  installs keep working; their scripts are kept and also shipped in the new skills.
- New scripts: accuracy assessment, choropleth layout, detection cleanup and scoring.
- Optional use of the TerraLab MCP server tools when connected; every skill works without them.

## 1.0.0 (2026-10-11)

- First release: eight focused skills, scripts, attribution reference, evaluations.
